# Optimization plan: modal_simple

Ideas for speeding up `src/shields/modal_simple.jl`. None of these is implemented yet. Each one has to give exactly the same `allowed` as now, or allow fewer choices.

| # | Idea | Why it should help | Soundness |
|---|------|--------------------|-----------|
| 1 | **Fast cells.** For each location, precompute per block of cells whether its whole-period flowpipe touches no guard, no unsafe set and no exit. For such a cell, skip `reach!` and take the cover of its end set directly, as `modal` does. | Most cells of large models touch nothing, and their `reach!` cost is the first-touch walk. | A block that touches nothing contains each of its cells, so each cell touches nothing either. Its successors are then exactly the end set's cells. |
| 2 | **Precompute end bounds per shape.** `end_bounds` computes `Φ * T` and its row sums for every cell. For a fixed (location, affine map, shape), `T′` and `abs(T′) * half` are constant, so only `T′ * center` changes. | Removes a D×D product and allocations per cell and choice. | Gives the same numbers. |
| 3 | ✅ **Done: fewer allocations in `cell_successors` and `reach!`.** The identity map is now stored in the context, `reached` returns sorted ids directly, the final set is flowed once instead of twice when exits are checked, and the `unique((D, total))` tuple is gone. Together with #10: ball 3.37 s → 3.21 s, oil pump 1.6 12.6 s → 12.0 s, cruise range 200 5.6 s → 4.4 s, with the same `allowed`. | | |
| 4 | **Jumped action sets per shape.** `jump_set(Z, M, j)` reduces the same generator matrix `M G` for every cell. Precompute it once per (location, action, shape), so that only the center changes per cell. | Saves an order reduction per cell and action. | Same set, provided the reduction is deterministic in `G` (it is). |
| 5 | **Threads over cells.** Cells are independent until `allowed_choices`. Split the cell loop across threads, with per-thread `CoverCache` and discretization caches. | Close to linear speedup on multi-core machines. | Gives the same result. |
| 6 | **Center/radius form in `affine_bounds`.** Compute `T m ± abs(T) r` from the box center `m` and radius `r`, instead of building two D×D `min.`/`max.` matrices. Combines well with #2. | One matrix-vector product and fewer temporary arrays per call. | Gives the same bounds mathematically. Rounding may differ by a few ulps, which is within `MODAL_TOL`. Check that `allowed` is unchanged. |
| 7 | **Precompute guard polyhedra for `box_meets`.** `box_meets` (used by `modal`) rebuilds an `HPolyhedron` from the halfspaces on every call. Build it once per guard in the context. | Saves allocations for every first-piece jump. | Same set. |
| 8 | ✅ **Done: function barrier for the noop loop.** Ball went from 3.8 s to 3.4 s with the same `allowed`. `allowed` comes from `reshape(allowed_choices(choice_type(n_acts), …))`, so its element type is only known at run time. The final loop in `simple_shield` therefore dispatches dynamically on every cell. Moving the loop into a function of its own lets Julia compile it for the concrete type. | 15% of the ball's time, measured. | Same result. |
| 9 | ✅ **Done: cache discretizations after jumps by generator matrix.** Oil pump 1.6 went from 16.5 s to 12.6 s. The `allowed` result is **not** identical: oil pump 0.2 has +20 dead cells, oil pump 1.6 has −19, and the ball, cruise and boost are unchanged. | 98.6% of the discretizations after jumps on oil pump repeat an earlier shape. | `CellDiscretization` pairs `G` with `ΦG` in the hull. `newReACTDiscretizePlus` instead reduces `ΦX ⊕ U` to `X`'s order, then pairs. Girard's hull lemma makes both sound for any pairing, and each is more precise in some cases. |
| 10 | ✅ **Done: cover lookup in `touching_cells`, keyed by `G` itself.** The bloated key is now built only on a miss. This also speeds up `modal`, with the same results. Timings are in #3. | | |
| 11 | **Fill levels lazily in `discretize_cell!`.** It fills every level δ⁻…δ⁺, but on the ball only 20% of the filled levels are ever read: 88.5% of discretizations read only δ⁺, because the cell touches nothing. Fill a level on its first read. | At most the 3% of the ball spent in `discretize_cell!`. It overlaps with #1, which skips these cells altogether. | Same sets. |
| 12 | **Share the discretization cache between locations with the same `Dynamics`.** On oil pump 1.6, 527 of 15638 cache builds (3%) duplicate one already built for another location with the same dynamics. | Small. | Same sets, because the key would include `U`. |
| 13 | **Incremental tests in `cells_in_cover`.** `cell_center_in_cover` recomputes every normal · (cell center − c) from scratch for each cell. Along the sweep axis that value changes by `normal[sweep] · g` per cell, so compute it once per line and update it as the sweep moves. | `cells_in_cover` is 11% of oil pump 1.6. | Same cells, up to rounding against the cover's `tol`. Check the hashes. |
